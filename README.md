# EgvoX — 30s Motion Graphic (Remotion)

1. `npm install`
2. `npm run dev`  → preview di Remotion Studio (komposisi `EgvoX-30s`)
3. `npm run build` → render `out/egvox-30s.mp4` (1920×1080, 30fps, 30 detik, H.264)

Timing: 01 (0–5s) · 02 (5–10s) · 03 (10–15s) · 04 (15–21s) · 05 (21–26s) · 06 (26–30s).
Voice-over & musik: taruh file di `public/` lalu tambahkan <Audio> (lihat catatan di bawah).
Catatan: footage POV adalah placeholder ilustrasi; ganti dengan footage egocentric asli dan logo resmi EgvoX.
